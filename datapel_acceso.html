DATAPEL // ESCRITORIO REMOTO

R020.9 ABRE ÚNICAMENTE EL ESCRITORIO REMOTO. SE RETIRÓ EL INTENTO DE INICIAR MANTO AUTOMÁTICAMENTE HASTA CONFIRMAR UNA CONEXIÓN ESTABLE EN PC Y MÓVIL.

SESIÓN ARMAVALIDANDO
TIPO DE ACCESOVALIDANDO
DISPOSITIVODETECTANDO

LA CONTRASEÑA LA SOLICITA WINDOWS / WINDOWS APP DIRECTAMENTE. ARMA SOLO PREPARA LA CONEXIÓN CON EL SERVIDOR Y EL USUARIO INDICADO.

WINDOWS YA INCLUYE CONEXIÓN A ESCRITORIO REMOTO. NO REQUIERE INSTALAR NADA.
VOLVER A ARMA
  1. Pulse DESCARGAR CONEXIÓN DATAPEL.
  2. Abra ARMA_DATAPEL.rdp.
  3. Windows abrirá Conexión a Escritorio remoto y pedirá la contraseña si no está guardada.
  4. Debe aparecer el escritorio completo de SERVIDOR03. No se intentará abrir Manto automáticamente.
EN ANDROID / IOS SE USA WINDOWS APP. ARMA YA NO INTENTA ENVIAR UNA URI RDP AL NAVEGADOR: PREPARA UN ARCHIVO .RDP ESTÁNDAR PARA ABRIRLO O COMPARTIRLO CON WINDOWS APP.
INSTALAR WINDOWS APP — ANDROIDINSTALAR WINDOWS APP — IOS/IPADOSVOLVER A ARMA
  1. Si ya instaló Windows App, pulse ABRIR / COMPARTIR CON WINDOWS APP.
  2. Cuando el teléfono muestre el menú de compartir/abrir, seleccione Windows App. Si su navegador no permite compartir archivos, ARMA descargará ARMA_DATAPEL.rdp.
  3. También puede pulsar DESCARGAR CONEXIÓN .RDP y abrir el archivo desde Descargas/Archivos con Windows App.
  4. Windows App solicitará la contraseña RDP si no está guardada. La sesión debe abrir el escritorio completo.
ESTE SISTEMA NO FUE IDENTIFICADO COMO WINDOWS, ANDROID O IOS/IPADOS. PUEDE DESCARGAR EL ARCHIVO .RDP Y ABRIRLO CON UN CLIENTE RDP COMPATIBLE.
VOLVER A ARMA
CONEXIÓN PREPARADA: ESCRITORIO COMPLETO. LA APLICACIÓN MANTO NO SE INICIA AUTOMÁTICAMENTE EN ESTA VERSIÓN.
