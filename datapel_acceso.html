Windows ya incluye Conexion a Escritorio remoto (mstsc.exe). Solo debe preparar este usuario Windows una vez. El instalador guarda dos conexiones RDP en una carpeta local oculta y registra el acceso directo de ARMA.

CONFIGURAR ESTE PC · UNA VEZ VOLVER A MAIN
No requiere Administrador. Debido a que no tenemos privilegios elevados, los archivos se guardan en %LOCALAPPDATA%\ARMA\RDP, no en C:\Windows. Despues de ejecutar el configurador, este abre MAIN y deja este navegador marcado como configurado.

En Android/iOS se usa Windows App. La primera vez puede importar la conexion RDP de respaldo y guardar sus credenciales dentro de Windows App. Despues MAIN intenta abrir Windows App directamente.

INSTALAR / VER WINDOWS APP IMPORTAR CONEXION .RDP · UNA VEZ VOLVER A MAIN
La clave no se envia por la HTML. Windows App la solicita y puede guardarla localmente. En Android, ARMA usa un Intent dirigido especificamente al paquete oficial com.microsoft.rdc.androidx para evitar que el navegador trate el enlace como una pagina web.

Este dispositivo no se identifico como Windows, Android o iOS.
